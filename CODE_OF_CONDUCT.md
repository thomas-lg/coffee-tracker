# Code of conduct

This is a small project run by one person. The whole policy is: **be decent to each
other.**

In practice that means assuming good faith, keeping criticism aimed at the code rather
than the person, and accepting that "no, thanks" is a complete answer to a feature
request. Harassment, personal attacks, and dragging unrelated grievances into a thread
about coffee software are not welcome.

This applies in issues, pull requests, commit messages, and anywhere else the project
is being discussed.

## If something goes wrong

Report it privately through
[a GitHub private vulnerability report](https://github.com/thomas-lg/coffee-tracker/security/advisories/new)
— it's the only private channel this repo has, and it works for conduct as well as
bugs. I read them.

I'll look into it and do whatever seems proportionate, which may mean editing or
deleting comments, or blocking someone from the repo. I'm the only maintainer, so
that judgement is mine, and I'll try to explain it.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/),
trimmed to something a one-person project can honestly promise to enforce.
